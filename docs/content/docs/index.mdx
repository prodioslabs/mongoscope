---
title: Introduction
description: Terminal UI for MongoDB slow queries, live ops, replication, indexes, and logs
---

MongoScope is a terminal UI for inspecting MongoDB slow queries, live operations, replication, indexes, and logs. Built with [Bun](https://bun.sh) and [OpenTUI](https://github.com/anomalyco/opentui).

Requires a real interactive TTY (do not pipe stdout).

Dashboard tabs (`1`–`5`, or Tab / Shift+Tab): **Slow Queries** · **Live Ops** · **Replication** · **Indexes** · **Logs**.

Install with the curl one-liner or from [GitHub Releases](https://github.com/prodioslabs/mongoscope/releases) — full steps in [Installation](/docs/installation). These pages are the deeper product reference.
