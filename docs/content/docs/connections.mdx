title: Connections
description: DbSelector, connections dialog, keychain storage, and Static vs Live
---

Press `c` on Live Ops / Replication / Indexes (or Ctrl+K → **Manage connections**). With no saved profiles, those tabs show an inline add form.

URIs are stored under service `com.mongoscope.cli` (OS keychain when available, otherwise plaintext in `config.json`).

After a connection is selected, Slow Queries and Logs can toggle **Static** vs **Live** with `l`.

There is no separate full-screen connections flow — switching, adding, editing, and deleting happen through **DbSelector** + the connections dialog.

## Credential store

Saved connections prefer `Bun.secrets`:

- macOS: Keychain
- Linux: Secret Service (GNOME Keyring, KWallet, etc.)

If `Bun.secrets` is missing or the OS credential store is unavailable, the same connections blob is stored in plaintext under `secrets` in `~/.config/mongoscope/config.json` (or `$XDG_CONFIG_HOME/mongoscope/config.json`). Theme settings in that file are preserved.

## CLI connection flags

`--uri` or `--host` / `--port` / `--username` / `--password` / `--auth-db` activate an **ephemeral** live connection for this session only — credentials are **not** written to the credential store. Use the in-app connections dialog to save a profile. See [CLI flags](/docs/cli).
