Press `?` in the app for the full, up-to-date list (sourced from `src/app/shortcuts/`).

## Global

| Key                       | Action            |
| ------------------------- | ----------------- |
| `?`                       | Help              |
| `Ctrl+K`                  | Command palette   |
| `m`                       | Toggle light/dark |
| `t`                       | Cycle theme       |
| `q`                       | Quit              |
| `1`–`5` / Tab / Shift+Tab | Dashboard tabs    |

## Connections

| Key | Action                                                                                   |
| --- | ---------------------------------------------------------------------------------------- |
| `c` | Connections dialog (on Live Ops / Replication / Indexes), or Ctrl+K → Manage connections |
| `l` | Toggle Static vs Live on Slow Queries and Logs (when a connection is selected)           |

## Slow Queries

| Key             | Action                                                             |
| --------------- | ------------------------------------------------------------------ |
| `l`             | Toggle Static / Live                                               |
| `e`             | Enable profiling (confirm dialog; level 1 + `slowms`, default 100) |
| `c` / `a` / `p` | Sort by count / avg ms / plan                                      |
| Enter           | Details                                                            |
| `i`             | Jump to Indexes with suggested vs existing index (from details)    |
| `Shift+T`       | Live sample window (presets / custom)                              |
| `[` / `]`       | Cycle databases                                                    |

## Live Ops

| Key | Action                                                              |
| --- | ------------------------------------------------------------------- |
| `x` | Confirm kill op                                                     |
| `e` | Jump to matching Slow Queries detail/explain when a pattern matches |

## Indexes

| Key       | Action                     |
| --------- | -------------------------- |
| `←` / `→` | Database                   |
| `[` / `]` | Collection                 |
| `↑` / `↓` | Rows                       |
| `n` / `i` | Sort collections           |
| `s` / `o` | Sort indexes by size / ops |

## Logs

| Key                         | Action         |
| --------------------------- | -------------- |
| `space`                     | Follow         |
| `/`                         | Search         |
| `f`                         | Custom filter  |
| `c` / `w` / `r` / `n` / `s` | Category pills |
