MongoScope is a terminal UI for inspecting MongoDB slow queries, live operations, replication, indexes, and logs. Use it when you need a local TTY workflow against log files, `system.profile`, or a live connection — not a browser dashboard.

It is built with [Bun](https://bun.sh) and [OpenTUI](https://github.com/anomalyco/opentui).

## Who this is for

- Operators and developers who already work in a terminal
- People debugging slow queries from MongoDB log files or a live profile
- Teams that need a quick view of `currentOp`, replica-set health, indexes, or recent server logs

## What you can do

Dashboard tabs (`1`–`5`, or Tab / Shift+Tab):

| Tab | Job |
| --- | --- |
| Slow Queries | Aggregate patterns from a log file or live `system.profile` |
| Live Ops | Watch `currentOp`, collection top, and kill an operation |
| Replication | Inspect topology, oplog window, lag, heartbeats, and elections |
| Indexes | Inventory indexes, builds, and suggested keys from Slow Queries |
| Logs | Tail a log file or poll the server `getLog` buffer |

## Requirements

- A real interactive TTY — do not pipe stdout
- For static analysis: a readable MongoDB log file
- For live tabs: a reachable MongoDB and a selected connection
