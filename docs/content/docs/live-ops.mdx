title: Live Ops

Use Live Ops to inspect active and queued operations and collection activity on a connected MongoDB.

## Prerequisites

- A selected live connection — see [Connections](/docs/connections)
- Permissions for `currentOp`, `top`, and (for kill) `killOp`

## What the tab shows

While the tab is open and connected, MongoScope polls about every 1 second.

| Area | Contents |
| ---- | -------- |
| Operations table | `currentOp` rows (active and queued). The plan column highlights `COLLSCAN` as error severity. |
| Collection top | Read/write time deltas from consecutive `top` samples (mongotop-style · 1s sample). The first poll is a baseline (“waiting for first sample…”). |
| Sidebar | Connections, queued ops, lock waits |

## Kill an operation

Killing an operation can interrupt in-flight work for that client.

1. Select the operation row.
2. Press `x`.
3. Confirm the dialog.

MongoScope runs `killOp` for that `opid`. Rows without a usable `opid` cannot be killed.

## Jump to Slow Queries explain

Press `e` on a selected operation to open matching Slow Queries detail when a pattern matches. If nothing matches, the jump does nothing useful for that row.
