---
title: Keyboard shortcuts
description: Global and per-tab keys for MongoScope
---

Press `?` in the app for the full, up-to-date list (sourced from `src/app/shortcuts/`).

## Global

| Key                       | Action              |
| ------------------------- | ------------------- |
| `?`                       | Help                |
| `Ctrl+K`                  | Command palette     |
| `m`                       | Toggle light / dark |
| `t`                       | Cycle theme         |
| `q`                       | Quit                |
| `1`–`5` / Tab / Shift+Tab | Dashboard tabs      |

## Welcome

| Key                   | Action                                                                                     |
| --------------------- | ------------------------------------------------------------------------------------------ |
| `↑` / `↓` / `j` / `k` | Navigate log files                                                                         |
| `tab`                 | Switch section (`/var/log/mongodb` ↔ `--log-dir`)                                          |
| `enter`               | Analyze selected log                                                                       |
| `r`                   | Retry with sudo when a log directory or selected file is permission-denied (confirm first) |

Welcome’s `r` is only bound on the Welcome screen. On the Logs tab, `r` is a category pill.

## Connections

| Key | Action                                                                                                            |
| --- | ----------------------------------------------------------------------------------------------------------------- |
| `c` | Connections dialog when DbSelector is shown and at least one saved profile exists; or Ctrl+K → Manage connections |
| `l` | Toggle Static vs Live on Slow Queries and Logs (when a connection is selected)                                    |

## Slow Queries

| Key                   | Action                                                                         |
| --------------------- | ------------------------------------------------------------------------------ |
| `l`                   | Toggle Static / Live                                                           |
| `e`                   | Enable profiling (confirm dialog; level 1 + `slowms`, default 100)             |
| `c` / `a` / `p` / `g` | Sort by count / avg ms / plan / regression (`g`: static only; live sorts as 0) |
| Enter                 | Details                                                                        |
| `i`                   | Jump to Indexes with suggested vs existing index (from details)                |
| `Shift+T`             | Static: log tail size. Live: profiler sample window                            |
| `[` / `]`             | Cycle databases (Live)                                                         |
| `x`                   | Export patterns (JSON / CSV / Markdown)                                        |

## Live Ops

| Key | Action                                                      |
| --- | ----------------------------------------------------------- |
| `x` | Confirm kill op                                             |
| `e` | Jump to matching Slow Queries detail when a pattern matches |

## Indexes

| Key                   | Action                                 |
| --------------------- | -------------------------------------- |
| `←` / `→`             | Database                               |
| `[` / `]`             | Collection                             |
| `↑` / `↓` / `j` / `k` | Rows                                   |
| `n` / `i`             | Sort collections by name / index count |
| `s` / `o`             | Sort indexes by size / ops             |

## Logs

| Key                         | Action                                                      |
| --------------------------- | ----------------------------------------------------------- |
| `space`                     | Follow                                                      |
| `/`                         | Search                                                      |
| `f`                         | Custom filter                                               |
| `c` / `w` / `r` / `n` / `s` | Category pills (COMMAND / WRITE / REPL / NETWORK / STORAGE) |
| `l`                         | Toggle Static / Live (when a connection is selected)        |

## Query Detail

| Key                   | Action                                                     |
| --------------------- | ---------------------------------------------------------- |
| `↑` / `↓` / `j` / `k` | Scroll details                                             |
| `pgup` / `pgdn`       | Page scroll                                                |
| `r`                   | Toggle raw sample                                          |
| `c`                   | Copy displayed detail (raw or curated)                     |
| `s`                   | Copy suggested index command                               |
| `i`                   | Jump to Indexes (focus collection + suggested vs existing) |
| `esc`                 | Close details                                              |
