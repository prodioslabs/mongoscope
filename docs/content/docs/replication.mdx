Use the Replication tab for a read-only view of replica-set health on the connected node.

## Prerequisites

- A selected live connection — see [Connections](/docs/connections)
- A replica set (standalone nodes have little useful topology data)
- Permissions for the replication and log commands the tab issues

## Refresh behavior

While the tab is open and connected, MongoScope refreshes about every 5 seconds. Open connections management with `c` when saved profiles exist.

## Panels

| Panel | Contents |
| ----- | -------- |
| Topology | Primary → secondaries tree with lag, priority, and votes |
| Oplog window | Size, fill, and growth |
| Lag trend | Sparkline of session samples since connect (~10 minute window). No historical backfill; needs at least two samples before the chart is meaningful. |
| Heartbeats | Ping edges from this node |
| Recent elections / state changes | Parsed from the server `getLog` RAM buffer — not a fixed multi-day history |
| Write concern | Default write concern. Majority wait is not exposed read-only and shows as `n/a`. |
